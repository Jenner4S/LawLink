| 项 | 为什么不动 |
|---|---|
| **42 个文件超 500 行** | 能干净拆的（`export-xlsx` 1069→194）已拆。剩下的是界面类大组件，超限根因是**状态耦合**（如 `important-item-dialog` 688 行、23 个 useState），强行按职责切会产生「十几个 props 的组件」，是另一种屎山。真要拆需先重构状态结构（useReducer / 分组），属架构决策 |

| **审计链分叉** | 撤销 `previousHash` 唯一索引后的已知形态（同事务写多条审计时共用前驱）。不影响可用性，`forks` 字段可查 |
| **本地库含压测样本（25 条 RACE）** | 审计不可删（触发器拦截）。**交付前应重建库**，而不是绕过防删设计 |

| **端到端升级未验** | 缺 v1.3.2 库样本；旧迁移链在空库无法从零重放（`2026*` 与 `v4*` 命名混排），造不出该样本 |
