## 六、已知边界（不变，仍成立）

- 同号查重**只提示不阻断**；渠道只两级；爽约**不自动重排**
- 风代**只存比例**、金额读时派生；坏账默认双人复核
- 报表「率」在分母为 0 时显示「—」，**不显示 0%**
- 坏账**已全额结清的案件拒绝登记**（不让账目说谎）
- 审计表禁删、**无自动归档**（分区方案已实测 3 秒可迁，等量级）
- cron 为进程内调度，单实例成立
